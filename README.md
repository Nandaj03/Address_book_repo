# Address Book Management System (C Project)

## 📌 Overview
This project is a console-based Address Book Management System implemented using the C programming language. It allows users to store, manage, and retrieve contact information efficiently with the help of file handling. The project focuses on building strong fundamentals in C programming and modular code design.

---

## 🚀 Features
- Create new contacts
- Search contacts by name, phone number, or email
- Edit existing contact details
- Delete contacts
- Display all saved contacts
- Store contact data permanently using files

---

## 🛠️ Technologies Used
- Programming Language: C
- Concepts Used:
  - Structures
  - File Handling
  - Pointers
  - Strings
  - Modular Programming
  - Header Files

---

## 📂 Project Structure
.
├── main.c          # Program entry point
├── contact.c       # Contact operations
├── contact.h       # Contact structure and function declarations
├── file.c          # File handling logic
├── file.h          # File handling declarations
├── populate.c      # Sample data population
├── populate.h      # Population function declarations
├── contact.csv     # File used to store contacts
└── README.md

---

## ▶️ How to Compile and Run
gcc main.c contact.c file.c populate.c -o addressbook
./addressbook
